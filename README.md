# Latex-App

**LatexApp** is a lightweight utility designed to convert AI-generated text and LaTeX mathematical expressions (such as outputs from ChatGPT) into clean, native, and easily readable Microsoft Word formatting. 

### The Problem
Copying and pasting text containing math formulas directly from AI chatbots into MS Word often results in broken formatting, raw LaTeX code (like `\frac{a}{b}` or `$$...$$`), and hard-to-read equations.

### The Solution
LatexApp bridges the gap between AI markdown/LaTeX outputs and Microsoft Word, ensuring that both your text and mathematical functions look just as clean and structured in your document as they do in the chat interface.

### Key Features
* **Seamless Math Conversion:** Transforms raw LaTeX syntax into readable, native Word equations.
* **Clean Text Formatting:** Preserves the visual structure of AI responses without markdown clutter.
* **Built for AI Workflows:** Specifically tailored for outputs from ChatGPT, Claude, Gemini, and other LLMs.
